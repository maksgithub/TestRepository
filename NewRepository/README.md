# New Repository

Це новий репозиторій з демонстраційним проєктом на C#.

## Огляд
- Приклад REST API з мінімальною конфігурацією.
- Приклади юніт-тестів.
- Інструкція зі швидкого запуску.

## Запуск
1. Встановіть .NET SDK версії 7.0 або вище.
2. Клонуйте репозиторій та відкрийте його у Visual Studio або VS Code.
3. Виконайте `dotnet run` для запуску застосунку та `dotnet test` для перевірки тестів.

## Структура
```
NewRepository/
├── src/             # Основний вихідний код
├── tests/           # Юніт-тести
└── README.md        # Цей файл з описом проєкту
```
